Examining PC Hardware: BIOS, UEFI & Device Manager

Before Windows loads, the firmware decides what hardware exists and where to boot from. You will change a boot order in BIOS setup, find the route into UEFI from inside Windows, and use Device Manager to read what hardware is installed and which driver runs it.

Why this lab matters

Every PC runs code before the operating system starts. That code is the firmware: the older BIOS or the newer UEFI. It tests the hardware at power-on (the POST), decides which drive to boot from, and holds settings such as boot passwords, Secure Boot, and the TPM. When a PC won't boot from a USB stick, won't accept a Windows 11 upgrade, or keeps forgetting the date, the fix is often in firmware setup.

Once Windows is running, Device Manager is the technician's first stop for hardware. It shows every device Windows knows about, flags the ones with problems, and lets you update, roll back, disable, or uninstall the driver that runs each one.

By the end you should be able to get into firmware setup two different ways, change the boot order safely, and read a device's driver, events, and resources in Device Manager.

Walkthrough

Task 1: Examine the BIOS configuration PDF 1.1, steps 1–7

🪟 On Win7

1Restart Win7 into BIOS setup

Open the Win7 console. On the login screen (don't sign in), click the up arrow next to the Shut down button and choose Restart. As soon as the screen goes dark, press F2 repeatedly until the PhoenixBIOS Setup Utility opens. If Windows starts loading instead, restart and try again.

Where people get stuck

The VM console has to have keyboard focus, or your F2 presses go nowhere. Click inside the console window before you click Restart.

2Tour the menus

There's no mouse in this utility. Use the arrow keys to move between the tabs along the top, Enter to select, and the key guide at the bottom for everything else. Review what each tab can view and change:

TabWhat it controls
MainBasic system configuration, such as the system clock
AdvancedPrinter port addresses, interrupts, I/O device configuration
SecurityUser and administrator passwords, hard disk boot-sector protection
BootThe boot sequence
ExitExit the utility with various save or discard options

Look, but don't change anything except the boot order. A wrong firmware setting can stop the machine from booting.

3Change the boot order

Select the Boot tab. Highlight Removable Devices and press - to move it down one level so Hard Drive is listed first. In this utility + moves an item up and - moves it down.

ScreenshotThe Boot tab with Hard Drive at the top of the list.

Why a tech does this

Putting the internal drive first stops the PC from trying to boot from a USB stick someone left plugged in. When you need to boot from USB, most PCs have a one-time boot menu (often F12) so you don't have to change the order.

4Save and exit

Go to the Exit tab, highlight Exit Saving Changes, press Enter, select Yes, and press Enter again. Win7 restarts with the new order.

Task 2: Reach UEFI settings from Windows 10 PDF 1.2, steps 1–11

🪟 On Win10

5Sign in to Win10

Open the Win10 console, click anywhere on the splash screen, and sign in as sysadmin with Train1ng$.

6Restart into Advanced startup

Click Start > Settings > Update & Security > Recovery. Under Advanced startup, click Restart now.

7Find the Advanced options

When the blue Choose an option screen appears, click Troubleshoot > Advanced options. View the tiles. On a UEFI PC a UEFI Firmware Settings tile would be here; it restarts straight into firmware setup. This VM uses legacy BIOS, so the tile is missing. That is expected. Click the back arrow.

ScreenshotThe Advanced options screen showing the tiles that are available.

8Back out and boot normally

Click the back arrow on the Troubleshoot page, then click Continue on Choose an option to start Windows normally.

Optional extra, not a lab step

On a real UEFI PC you can reach the same screens from an elevated Command Prompt. Don't run these in the lab; they restart the VM.

shutdown /r /o /t 0 restarts into Advanced startup. shutdown /r /fw /t 0 restarts straight into UEFI firmware setup (UEFI PCs only). Holding Shift while you click Restart also opens Advanced startup.

Task 3: Device Manager from Control Panel PDF 2.1, steps 1–11

🪟 On Win7

9Open Device Manager

Sign in to Win7 as sysadmin with Train1ng$. Click Start > Control Panel, change View by to Small icons, and click Device Manager.

10Show hidden devices

Click View on the menu bar to see the other views (the default is Devices by type), then select Show hidden devices. That adds non-Plug and Play drivers, low-level system drivers, and drivers installed by third-party software.

11Read the hardware

Click the arrow next to Processors to see the CPU model and speed, then the arrow next to Mice and other pointing devices.

ScreenshotDevice Manager with hidden devices shown and Processors expanded.

12Inspect the driver, and don't roll it back

Right-click VMware Pointing Device and click Properties. Windows 7 shows four tabs: General, Driver, Details, and Resources. On the Driver tab, review the buttons, then click Roll Back Driver, read the prompt, and click No.

ScreenshotThe Driver tab or the Roll Back confirmation prompt.

13Check the resources

Click the Resources tab. It lists the resources the device uses (here an IRQ) and a Conflicting device list at the bottom. Don't change these settings. Click OK and close the remaining windows.

For comparison

On Windows 8.1 and 10, the PDF notes you can also right-click Start > Control Panel > Device Manager. Later Windows 10 builds and Windows 11 replaced Control Panel on that menu with Settings, so use Device Manager from the same right-click menu instead.

Task 4: Device Manager through Run PDF 2.2, steps 1–11

🪟 On Win10

14Open Run

Switch to Win10 and sign in if needed. Right-click Start to open the Power User menu and click Run.

15Launch Device Manager

In the Run box, type the command below and click OK.

Run box: devmgmt.msc

16Open the display adapter

Expand Display adapters, right-click the adapter (VMware SVGA 3D), and click Properties. Windows 10 shows five tabs: General, Driver, Details, Events, and Resources.

17Read the device's history

Click the Events tab. It lists when the device was installed, started, configured, or updated. Click View All Events to open Event Viewer, then click the Details tab in the main pane and review it. Close Event Viewer.

ScreenshotThe Events tab or the Event Viewer details for the display adapter.

18Finish

Click OK to close the Properties window. The lab is complete.

Reference: firmware and Device Manager

BIOS compared with UEFI

Legacy BIOSUEFI
InterfaceText menus, keyboard onlyOften graphical, with mouse support
Boot disk formatMBR: disks up to about 2 TB, four primary partitionsGPT: very large disks, up to 128 partitions in Windows
SecuritySetup and boot passwordsAdds Secure Boot, which blocks unsigned boot loaders
Windows 11Not supportedRequired, with Secure Boot capability and TPM 2.0
Older OS supportNativeThrough CSM (Compatibility Support Module) if the board offers it

Firmware settings you'll be asked about

  • Boot options: boot order, one-time boot menu, USB and network (PXE) boot.
  • Passwords: a supervisor (administrator) password protects setup; a user or power-on password is needed to boot at all.
  • Secure Boot and TPM: both needed for Windows 11, and the TPM is used by BitLocker (Lab 15).
  • Virtualization: Intel VT-x or AMD-V must be on for Hyper-V (Lab 16).
  • Hardware monitoring: CPU temperature, fan speeds, and voltages.
  • USB permissions: enable or disable ports, often for security.

Getting into setup

The key depends on the board maker, not Windows. Watch the boot screen or check the manual. Common setup keys are Del, F2, F10, F1, and Esc. One-time boot menus are often F12, F11, F9, or F8.

Professional habit

Before you change a firmware setting on someone else's PC, write down the current value. If the change causes a problem, you can put it back exactly, and your ticket notes show what you did.

High-yield facts

  • The setup key comes from the board maker, not the operating system.
  • UEFI pairs with GPT disks; legacy BIOS pairs with MBR. Windows 11 requires UEFI, Secure Boot capability, and TPM 2.0.
  • Supervisor password protects setup; user or power-on password protects booting.
  • Wrong time and lost settings after power-off point to a dead CMOS battery.
  • devmgmt.msc opens Device Manager. A yellow "!" means a problem; a down arrow means disabled.
  • Roll Back Driver is the first fix when a device fails right after a driver update.

Check yourself

1. A user's PC keeps trying to boot from a USB drive left in the port. What setting do you change, and where?

The boot order, in BIOS/UEFI setup. Put the internal drive first. For the rare times you need USB boot, use the one-time boot menu instead.

2. You're upgrading a PC to Windows 11 and the check fails on Secure Boot. The disk is MBR. What has to change?

Secure Boot needs UEFI boot mode, and UEFI boots from GPT disks. Convert the disk to GPT (Windows includes the mbr2gpt tool), switch firmware to UEFI, then enable Secure Boot.

3. A network adapter stopped working right after a driver update. What's the fastest fix in Device Manager?

Properties > Driver > Roll Back Driver, which restores the previous driver version.

4. Why might the UEFI Firmware Settings tile be missing from Advanced options?

The PC is running in legacy BIOS mode (or Windows was installed in legacy mode). The tile appears only on UEFI installations.

5. What does Show hidden devices add to the Device Manager list?

Non-Plug and Play drivers, low-level system drivers, drivers installed by other software, and devices that were installed but aren't connected now.

Cheat sheet

Firmware

  • Setup key: Del, F2, F10, Esc (board-specific)
  • One-time boot menu: often F12
  • From Windows: Shift+Restart
  • shutdown /r /o /t 0 opens Advanced startup
  • shutdown /r /fw /t 0 opens UEFI setup
  • UEFI + GPT + Secure Boot + TPM 2.0 for Windows 11
  • Clock resets: CMOS battery

Device Manager

  • devmgmt.msc or Win+X
  • View > Show hidden devices
  • "!" problem, down arrow disabled
  • Code 10 can't start, 22 disabled, 28 no driver, 43 reported problem
  • Broke after update: Roll Back Driver
  • Clean reinstall: Uninstall, then Scan for hardware changes
  • Events tab: device history (Windows 10 and later)
