Why this lab matters

Every software install is a decision. Does the PC meet the requirements? Is it the 32-bit or 64-bit version? Does the user have rights to install it, and should they? Is the license OK for work use? Did the installer come from a source you trust?

In this lab you install 7-Zip (a compression tool) and CPU-Z (a hardware information tool) on Windows, watching where each one goes and what it adds. Then you install LibreOffice on Linux using dpkg and sudo, which shows how Linux handles the same job with packages instead of setup wizards.

Walkthrough

Task 1: Install 7-Zip (Win7)

1Run the installer

Log in to Win7, open the Installs folder, and double-click 7z1801. Accept the UAC prompt.

Why UAC appears

Only administrators can install software for all users. A standard user would be asked for an admin's credentials here; an admin is asked to confirm.

2Keep the default location

Leave the folder as C:\Program Files\7-Zip and click Install, then Close.

Program Files or Program Files (x86)?

On 64-bit Windows, 64-bit programs go in C:\Program Files and 32-bit programs in C:\Program Files (x86). A 32-bit Windows has only Program Files and can't run 64-bit programs.

3Find what it added

Open Start > All Programs > 7-Zip > 7-Zip File Manager. Then in the Installs folder, right-click 7z1801: the 7-Zip submenu is new. Installers often add shortcuts, context-menu entries, and file associations as well as the program itself.

ScreenshotThe right-click menu showing the 7-Zip submenu.

Task 2: Install CPU-Z (Win7)

4Run the installer

In Installs, double-click cpu-z_1.83-en.exe, click Run at the security warning, and accept UAC. Accept the agreement.

5Choose the location and options

Set the location to C:\Program Files\CPU-Z and click Next. Keep the Start Menu folder (CPUID\CPU-Z) and the desktop icon option, click Install, then Finish. Read the readme that opens and close it.

Double-click the CPUID CPU-Z desktop icon and accept UAC. Look through the tabs:

CPU-Z only reads information and changes nothing. Close it.

Task 1 - Software Installation in Windows

Task 1.0 - Installing 7-Zip Compression Utility

1 Access the Win7 machine.

2 Log in as sysadmin using the password Train1ng$ followed by pressing the Enter key or clicking the arrow button.

3 Once logged in, double-click on the Installs folder located on the desktop.

4 Double-click on the 7z1801 executable application file to launch the setup wizard for 7-Zip.

5 When prompted with user account control, click Yes to continue. One of the security features that Microsoft added to the Windows operating system is User Account Control. One of the ways that Windows will protect itself from the possible installation of malicious software is to only allow administrators to install software. If a software package installation is attempted by a standard user, Even when installing software as an administrator, Windows will ask for confirmation before beginning the installation.

Note

Windows will ask for the username and password of an administrator.

6 The first step of this installation wizard is to ask where to install the program. The typical default location is C:\Program Files\<program name> (in this case, program name is 7-Zip). Leave the defaults and click the Install button. On a 64-bit system, there are two default install location. The first location is called Program Files (x86) which is for older 32-bit programs. The second default location is called Program Files which is for the new 64-bit programs.

7 Notice that the 7-Zip application is now installed. Click Close.

8 To run the software, click on the Start button, navigate to All Programs, open the 7-Zip folder, and then click on 7-Zip File Manager.

9 The program's main window will appear. You can create/modify compressed files here. Alternatively, 7-Zip will also install a connection into the context menu of Windows Explorer, so you can create/modify files with 7-Zip by right-clicking on files or folders. Change focus to the Windows Explorer with the Installs folder opened and right-click on the 7z1801 file; notice the available 7-Zip options.

    Task 2 - Software Installation in Linux

    Task 2.1 - Installing LibreOffice

    1 Access the Lubuntu system from the topology.

    2 Sign as the sysadmin using Train1ng$ as the password.

    3 On the taskbar, click on the File Manager icon.

    4 In the /home/sysadmin directory, double-click on the Downloads folder.

    5 In the Downloads folder, you will see a compressed LibreOffice installer file. Double-click on the LibreOffice_6.0.1_Linux_x86-64_deb.tar.gz file.

    6 The compressed file window will open, and you will see the contents. Click the Extract button.

    7 In the Extract window, click on Desktop and click Extract.

    8 Once the extraction of the files is completed, click Quit.

    9 Click on the LXTerminal icon in the taskbar to launch the terminal.

    10 In the terminal window, type the command below, followed by pressing the Enter key. This will change your current working directory to the desktop. sysadmin@lubuntu:~$ cd Desktop

    11 Enter the ls command to verify that the LibreOffice file exists.

    sysadmin@lubuntu:~/Desktop$ ls

    12 Now, enter the command below to change to the LibreOffice installation location. When typing out long names, using the Tab key can be useful as it can be used as an auto complete feature. For this example, typing Li followed by pressing the Tab key will auto complete the full name.

    sysadmin@lubuntu:~/Desktop$ cd LibreOffice_6.0.1.1_Linux_x86-64_deb

    13 Enter the command below to change to the folder that contains the actual installation files.

    sysadmin@lubuntu:~/Desktop/LibreOffice_6.0.1.1_Linux_x86-64_deb$ cd DEBS

    14 Enter the command below to begin the installation. This command will run the dpkg utility, which is the package manager for Debian-based Linux systems. It can install, remove, and build packages, but it cannot perform an automatic download/installation like apt-get. If prompted for the sudo password, enter Train1ng$. The switch used with dpkg uses a lower-case i to indicate install. The sudo part of the syntax is short for Super User Do. It tells Linux that the software is to be run with root, or Super User privileges. The -i switch tells dpkg to install the package(s). In this case, all the packages that have the .deb extension in the current folder

    sysadmin@lubuntu:~/Desktop/LibreOffice_6.0.1.1_Linux_x86-64_deb/DEBS$ sudo dpkg -i *.deb

    Reference: installing software

    Before you install

    CheckWhy
    System requirementsCPU, RAM, storage, OS version, and graphics must meet the minimum
    32-bit or 64-bitA 64-bit OS runs both; a 32-bit OS runs only 32-bit
    SourceVendor site, Microsoft Store, winget, or your organization's software portal. Avoid download mirrors and "free" cracked copies.
    IntegrityCompare the file's hash with the vendor's published one
    LicensePersonal, commercial, per-seat, subscription, open source
    RightsStandard users can't install for all users; deploy centrally or elevate
    ImpactWill it change startup, firewall, file associations, or other apps? Test first on business PCs.

    Verify a download's hash

    Windows (cmd)
certutil -hashfile 7z1801.exe SHA256
Windows (PowerShell)
Get-FileHash .\7z1801.exe -Algorithm SHA256
Linux
sha256sum LibreOffice_6.0.1_Linux_x86-64_deb.tar.gz

    On the A+ exams

    Core 2: Operating Systems

    Core 2 (220-1202) covers application installation: system requirements (CPU, 32/64-bit, RAM, storage, graphics), distribution methods (download, ISO/mountable image, Store, package manager), licensing, impact on the device, network, and organization, and Linux package management with apt and dnf.

    High-yield facts

    • 64-bit Windows: Program Files for 64-bit apps, Program Files (x86) for 32-bit.
    • A 32-bit OS can't run 64-bit apps or use more than 4 GB of RAM.
    • Verify installers with a hash (certutil -hashfile, Get-FileHash, sha256sum).
    • apt (Debian/Ubuntu) and dnf (Red Hat family) resolve dependencies; dpkg and rpm don't.
    • sudo runs a command as root.
    • Mount an ISO to install from a disc image.

    Check yourself

    1. A user tries to install a 64-bit program on a PC with 32-bit Windows. What happens and what's the fix?

    It won't run. Install the 32-bit version of the program, or upgrade to 64-bit Windows if the hardware supports it.

    2. What's the difference between dpkg -i package.deb and apt install package?

    dpkg installs a local package file without fetching dependencies. apt downloads the package and all its dependencies from the repositories.

    3. How do you confirm a downloaded installer hasn't been tampered with?

    Compute its hash (for example certutil -hashfile file SHA256) and compare it with the hash the vendor publishes.

    4. Where would Windows install a 32-bit application on a 64-bit PC?

    C:\Program Files (x86)

    5. Why did UAC prompt you even though sysadmin is an administrator?

    UAC asks administrators to confirm before changes that affect the whole system, such as installing software, so malware can't install silently.
