How to use a companion page

Open the lab in NETLAB and its companion in a second window. Read the overview and "Then vs. now" before you start, follow the walkthrough as you work, and take a screenshot wherever you see Screenshot. The evidence checklist at the end of each page lists every screenshot to submit. Your checkmarks are saved in this browser only.

The lab machines run Windows 7, 8.1, and 10, which are now retired. Each page shows where the same setting lives on Windows 11, which is what the current A+ exams and most workplaces expect.

The labs

  1. Lab 01-A

    Examining PC Hardware: BIOS, UEFI & Device Manager

    Enter the firmware setup, change the boot order, reach UEFI from Windows, and read hardware and driver details in Device Manager.

    Tools: BIOS setup, Advanced startup, devmgmt.msc

    Core 1: HardwareCore 2: Operating Systems

  2. Lab 01-B

    Examining PC Hardware: System Information Tools

    Inventory a PC with the System applet, systeminfo, msinfo32, dxdiag, and a third-party audit tool.

    Tools: systeminfo, msinfo32, dxdiag, Free PC Audit

    Core 1: HardwareCore 2: Operating Systems

  3. Lab 02

    Windows Management & Administrative Tools

    Build an MMC console, schedule a task, create a volume, and work in Task Manager, Resource Monitor, and the Registry.

    Tools: mmc, taskschd.msc, diskmgmt.msc, taskmgr, resmon, regedit

    Core 2: Operating Systems

  4. Lab 03

    Windows Network Settings

    Configure adapters and sharing settings, run the network troubleshooter, and use the networking command-line tools.

    Tools: ncpa.cpl, ipconfig, ping, tracert, nslookup

    Core 1: NetworkingCore 2: Operating Systems

  5. Lab 04

    Windows Users & Groups

    Create and manage local accounts, use Local Users and Groups, set local Group Policy, and open Active Directory Users and Computers.

    Tools: lusrmgr.msc, gpedit.msc, RSAT, dsa.msc

    Core 2: Operating SystemsCore 2: Security

  6. Lab 05

    Sharing Resources: Folders

    Join machines to a workgroup, set network discovery, and share a folder with the right share and NTFS permissions.

    Tools: sysdm.cpl, Advanced sharing, NTFS permissions

    Core 2: Operating SystemsCore 2: Security

  7. Lab 06

    Sharing Resources: Printers

    Add a local printer, share it, and connect to it from another workgroup machine.

    Tools: Devices and Printers, printer sharing

    Core 1: HardwareCore 2: Operating Systems

    Disk Maintenance & Data Recovery

    Run and schedule Disk Cleanup, optimize drives, create restore points, and back up and find files across machines.

    Tools: cleanmgr, dfrgui, System Restore, Backup

    Core 2: Operating SystemsCore 2: Operational Procedures

    Command Line: Windows & Linux

    Core 2: Operating Systems

  10. Lab 09

    Windows Control Panel & Settings
