Disk Maintenance & Data Recovery

Regular maintenance keeps a PC fast, and backups are the only thing that saves a user's files when it fails. You will clean up and optimize a drive on a schedule, roll a system back with a restore point, and back up and restore files with two different Windows tools.

Why this lab matters

Maintenance and recovery are two sides of the same job. Disk Cleanup and Optimize Drives keep storage healthy and are easy to automate. System Restore undoes system changes such as a bad driver or update, without touching personal files. Backup and Restore and File History protect the personal files themselves.

Knowing which tool fixes which problem is the point. A restore point won't bring back a deleted spreadsheet, and a file backup won't fix a broken driver. And a backup you've never restored from is only a hope, which is why this lab has you delete a folder and get it back.

Walkthrough

Task 1: Disk Cleanup (Win8.1)

1Run a cleanup

Log in to Win8.1. Right-click Start > Search, type disk cleanup, and open Free up disk space by deleting unnecessary files. Wait for the scan.

2Include system files

Click Clean up system files. It rescans and adds system areas (such as old update files and error reports) that only an administrator can clean. Click each item to read its description, note the total space, and click OK > Delete Files. It takes 2–3 minutes and closes on its own.

ScreenshotThe Disk Cleanup window after Clean up system files, showing the items and total space.

Task 2: Schedule a cleanup (Win8.1)

3Save a cleanup profile

Right-click Start > Search, type the command below, and open it:

cleanmgr /sageset:1

Click Clean up system files, check every box, and click OK. This saves your choices in the Registry as profile 1.

4Create a basic task

Open Control Panel > Administrative Tools > Task Scheduler and click Create Basic Task in the Actions pane:

Wizard pageValue
NameDisk Cleanup
TriggerWeekly, recur every 1 week, today's day, start 10–15 minutes from now
ActionStart a program
Program/scriptC:\Windows\System32\cleanmgr.exe
Add arguments/sagerun:1

Click Finish.

5Set it for Windows 8.1 and watch it run

In Task Scheduler Library, double-click Disk Cleanup, change Configure for to Windows 8.1, and click OK. When the start time passes, the status shows Running, or check Last Run Time.

ScreenshotTask Scheduler Library showing the Disk Cleanup task with its trigger or Last Run Time.

Task 3: Optimize the drive (Win8.1)

6Turn on scheduled optimization

In Administrative Tools, open Defragment and Optimize Drives. Under Scheduled optimization, click Turn on, check Run on a schedule, choose Weekly, and click OK.

7Analyze, then optimize

Select (C:) and click Analyze. Note the percent fragmented in Current status. Then click Optimize (3–4 minutes) and check the new percentage.

ScreenshotOptimize Drives showing C: after optimization.

Task 4: System Restore (Win8.1)

8Create a restore point

Open Control Panel > System > System protection and click Create. Name it Background Configuration and click Create, then Close.

9Make a change you can see

Right-click the desktop > Personalize > Desktop Background. Choose Solid Colors and a different color, and click Save changes.

10Roll back

Back on the System Protection tab, click System Restore > Next. Select Background Configuration, click Next > Finish, and confirm with Yes. Windows restarts (about 8 minutes). Sign back in: the background is the original color. Click Close on the confirmation.

ScreenshotThe System Restore confirmation after signing back in.

What System Restore does and doesn't touch

It rolls back system files, installed programs, drivers, settings, and the Registry. It doesn't restore or delete personal files such as documents and photos.

Task 5: Backup and Restore (Win7)

11Set up the backup

Log in to Win7. Open Start > All Programs > Maintenance > Backup and Restore > Set up backup. Choose Data (E:) as the destination, then Let me choose. Check all the Data Files boxes and Local Disk (C:), and uncheck Include a system image. Review the schedule and click Save settings and run backup (about 4 minutes).

12Delete the Installs folder for real

Right-click Installs on the desktop > Delete > Yes. Then right-click the Recycle Bin > Empty Recycle Bin > Yes. The folder is gone.

13Restore it

In Backup and Restore, click Restore my files > Browse for folders. Open sysadmin's backup > Desktop, select Installs, click Add folder, then Next. Keep In the original location and click Restore, then Finish. Open Installs to confirm the files are back.

ScreenshotThe Restore Files window with the Installs folder selected, or the restored folder on the desktop.

Task 6: File History (Win10)

14Point File History at a network share

Log in to Win10. Open Control Panel > Save backup copies of your files with File History. Click Select a network location > Add network location, double-click Win8-1, select Backup, and click Select folder. Highlight \\WIN8-1\Backup and click OK.

15Exclude everything but Documents

Click Exclude folders > Add and add each library except Documents (Camera Roll, Music, Pictures, Saved Pictures, Videos), one at a time. Click Save changes. Look through Advanced settings (how often to save, how long to keep versions) and click Cancel.

16Turn it on

Click Turn on. When the first backup finishes you'll see its time, and Run now becomes available.

ScreenshotFile History turned on, showing the network location and last backup time.

17Find the backup on Win8.1

On Win8.1, right-click Start > Command Prompt (Admin) and run:

cd C:\Users\sysadmin\Documents\Backup\sysadmin\Win10
dir

You'll see Configuration and Data folders. The backed-up files are under Data.

ScreenshotThe dir output on Win8.1 showing the File History folders.

The lab is complete.

cleanmgr switches

SwitchDoes
/sageset:nChoose items and save them as profile n
/sagerun:nRun profile n without prompts
/d C:Clean a specific drive
/verylowdiskClean everything without asking and show a summary

defrag from the command line

defrag C: /A
defrag C: /O
defrag /C /H /U

/A analyzes, /O does the right optimization for the media type (defrag or TRIM), and /C /H /U optimizes all volumes at normal priority with progress.

The 3-2-1 rule

Keep 3 copies of important data, on 2 different kinds of media, with 1 copy offsite (or in the cloud). File History to a share on the same network is one copy, not an offsite one.

Test your restores

Schedule a test restore, like the Installs folder in this lab. A backup job that reports success but can't be restored is worse than none, because nobody knows it's broken.

High-yield facts

  • System Restore fixes system changes, not deleted personal files.
  • Don't defragment SSDs; Optimize Drives sends TRIM instead.
  • Incremental: fastest backups, slowest restore. Differential: the reverse.
  • 3-2-1: three copies, two media types, one offsite.
  • Test restores on a schedule.
  • cleanmgr /sageset:n then /sagerun:n for automated cleanup.

Check yourself

1. A user deleted a folder last week and emptied the Recycle Bin. Will System Restore get it back?

No. System Restore doesn't restore personal files. Use File History, Previous Versions, or a backup.

2. You do a full backup Sunday and differentials Monday through Thursday. The drive fails Friday morning. What do you restore?

Sunday's full backup, then Thursday's differential.

3. Why doesn't Windows defragment an SSD?

SSDs have no moving parts, so fragmentation doesn't slow them, and extra writes wear them out. Optimize Drives sends TRIM instead.

4. Which two commands set up and run a saved Disk Cleanup profile?

cleanmgr /sageset:1 to choose and save the items, then cleanmgr /sagerun:1 to run them, for example from Task Scheduler.

5. Your only backup is File History to a share on the office NAS. Does that meet 3-2-1?

No. It's a second copy on one more device, but there's no offsite copy. Add a cloud or offsite backup.

Cheat sheet

Maintain

  • cleanmgr > Clean up system files
  • cleanmgr /sageset:1 then /sagerun:1
  • Windows 11: Storage Sense
  • dfrgui or defrag C: /O
  • HDD: defragment. SSD: TRIM only.

Recover

  • Restore point first, then make the change
  • rstrui = System Restore (system, not files)
  • File History / Previous Versions = files
  • Full, incremental, differential
  • 3-2-1 and test the restore
