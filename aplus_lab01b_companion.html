Examining PC Hardware: System Information Tools

Before you troubleshoot a PC you need to know exactly what's in it. You will inventory the same machines four ways (the System applet, systeminfo, msinfo32, and dxdiag), save reports you can hand to another tech, and compare them with a third-party audit tool.

Why this lab matters

Most help desk calls start with the same questions: what Windows edition is this, how much RAM, which CPU, what's the BIOS version, which driver is the display using? Windows answers all of them without installing anything, but each tool answers at a different depth.

The System page gives a one-glance summary. systeminfo dumps text you can copy into a ticket. msinfo32 (System Information) is the deep inventory, and it can export a report. dxdiag focuses on display, sound, and input, and its saved report is what game and video vendors ask for.

The habit this lab builds is saving a baseline report while a system is healthy, so you can compare after something changes.

Walkthrough

Task 1: The System Control Panel applet PDF 1.1–1.2

🪟 On Win7

1Read the summary on Win7

Open the Win7 console and sign in as sysadmin with Train1ng$. Click Start > Control Panel, set View by to Small icons, and click System. Note the Windows edition, processor, memory, system type (32- or 64-bit), computer name, and product ID. Close the window.

🪟 On Win8.1

2Use the Power User menu on Win8.1

Open the Win8.1 console, click the splash screen, and sign in as sysadmin with Train1ng$. Right-click Start (lower-left corner of the taskbar) and click System. It's the same page, reached faster. Review the same details and close the window.

Task 2: systeminfo.exe PDF 2.1–2.2

🪟 On Win7

3Open an elevated Command Prompt on Win7

Change focus back to Win7. Click Start, type command prompt in the search box, right-click the first Command Prompt result, and choose Run as administrator. Click Yes at the User Account Control prompt.

4Run systeminfo, then exit

C:\Windows\System32> systeminfo.exe

Scroll up and review the output: OS version and build, install date, BIOS version, processor, total memory, hotfixes, and network adapters. Then close the prompt:

C:\Windows\System32> exit

ScreenshotThe systeminfo output on Win7, showing the OS and BIOS lines.

🪟 On Win10

5Run it on Win10

Open the Win10 console, click the splash screen, and sign in as sysadmin with Train1ng$. Right-click Start, click Run, type the command below, and press Enter:

Run box: cmd

In the Command Prompt window, run systeminfo, review the output, and exit:

C:\Windows\System32> systeminfo.exe
C:\Windows\System32> exit
Which prompt will you actually see?

The PDF shows C:\Windows\System32> for both machines. A Command Prompt opened from Run usually starts in C:\Users\sysadmin> instead. The command works the same from either folder.

Leave Win10 open for the next task.

Task 3: The MSInfo32 utility PDF 3.1–3.2

🪟 On Win10

6Open System Information

On Win10, right-click Start > Run, type the command below, and press Enter (or click OK):

Run box: msinfo32.exe

In the left panel, click the + next to each category (System Summary, Hardware Resources, Components, Software Environment) to see what each holds. Then click System Summary and inspect the system model, system type, processor, memory, and BIOS information.

7Find the display adapter

Type Display in Find what at the bottom of the window and click Find (click Find Next if needed). It finds Components > Display.

Where people get stuck

Find matches exact category names and values. Search for Display, not "graphics card". If you get nothing, check that Search selected category only is unchecked.

8Export a report

With Components > Display selected, choose File > Export. In the Export As dialog, click Documents in Quick access. Right-click in the white space, choose New > New Folder, name it System Info, press Enter, and double-click it. In File name type <date>-display_info (for example 20261017-display_info) and click Save.

ScreenshotThe Export As dialog showing the System Info folder and your file name.

9Open the report

Close System Information. Open File Explorer from the taskbar, go to Documents > System Info, and double-click your file. It's a text file with the display adapter information. Close the windows.

Best practice from the PDF

Save a copy of reports like this somewhere off the PC, so you can still read them if the system won't boot.

Task 4: DirectX Diagnostic Tool PDF 4.1

🪟 On Win7

10Launch dxdiag on Win7

Change focus back to Win7. Click Start, type dxdiag in the search box, and click the dxdiag result. (Run box dxdiag.exe also works.) When it asks whether to check that drivers are digitally signed, click No for this lab.

11Read the tabs

Click Next Page to move through System, Display, Sound, and Input. Check the Notes pane at the bottom of each page; problems are described there.

12Save the report

Click Save All Information. In the Save As window click Desktop, keep the file name DxDiag, and click Save. Double-click the DxDiag file on the desktop, review it, and close Notepad. Close any other windows but leave Win7 open.

ScreenshotThe DxDiag.txt file open in Notepad.

Task 5: Free PC Audit PDF 5.1

🪟 On Win7

13Run the audit

On Win7, right-click the Free PC Audit desktop shortcut and choose Run as administrator. Click Yes at UAC. When the analysis finishes, scroll through the System tab; it also lists shares and Windows Update hotfixes.

ScreenshotFree PC Audit results on the System tab.

Export or save?

File > Export writes plain text for the selected category. File > Save writes an .nfo file of everything, which another tech can open in msinfo32 on their own PC.

Professional habit

Keep a baseline report for every PC you set up. When it misbehaves later, you can see exactly what changed.

On the A+ exams

Core 1: HardwareCore 2: Operating Systems

Core 2 (220-1202) expects you to know which Windows tool to use for a task, by name and by its shortcut: msinfo32, dxdiag, systeminfo, and the System settings page. Core 1 (220-1201) builds on this when you identify RAM, CPU, and storage in a system.

High-yield facts

  • msinfo32 is System Information: the most detailed built-in inventory, with export.
  • dxdiag is for display, sound, and input; check the Notes box for problems.
  • systeminfo is the command-line summary, including installed hotfixes.
  • System Summary in msinfo32 shows BIOS Mode and Secure Boot State, useful for Windows 11 readiness.
  • 32-bit Windows can't use more than 4 GB of RAM; check System type.
  • Baseline documentation is part of good operational procedure.

Check yourself

1. A vendor asks for a full list of your PC's components and drivers in one file. Which tool do you use?

System Information (msinfo32). Use File > Export for text, or File > Save for an .nfo file.

2. Which command lists installed hotfixes from the command line?

systeminfo. The Hotfix(s) section lists installed updates by KB number.

3. A user's video player stutters. Which built-in tool shows the display driver version and flags DirectX problems?

The DirectX Diagnostic Tool (dxdiag). Problems appear in the Notes box on the Display tab.

4. Where can you check whether a PC is booting in UEFI mode without restarting?

msinfo32 > System Summary > BIOS Mode.

5. Why save a system report while the PC is working fine?

It's a baseline. When something breaks, you compare against it to see what changed, even if the PC won't boot.

Cheat sheet

Quick specs

  • Win+Pause or Settings > System > About
  • systeminfo for text and hotfixes
  • systeminfo > file.txt to save it
  • Get-ComputerInfo in PowerShell

Deep inventory

  • msinfo32: System Summary, Hardware Resources, Components, Software Environment
  • Export = .txt of one category; Save = full .nfo
  • BIOS Mode and Secure Boot State in System Summary
  • dxdiag: Display, Sound, Input; read Notes; Save All Information
