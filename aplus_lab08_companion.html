Command Line: Windows & Linux

When the desktop won't load or you're working remotely, the command line is how you get things done. You will navigate, create, copy, rename, and delete files and folders in the Windows Command Prompt and the Linux terminal, and manage processes from an elevated prompt.

Why this lab matters

Every technician needs the command line. It works in Windows Recovery when the desktop won't start, over a remote shell, in scripts (Lab 17), and on the Linux servers and appliances you'll meet sooner than you expect.

This lab does the same set of jobs twice, once in Windows cmd and once in the Linux shell: find out where you are, list what's there, move around, make folders and files, copy, rename, and delete. Doing them side by side is the fastest way to learn both, because the ideas are identical and only the command names change.

You'll also see why some commands need an elevated (administrator) prompt, and use tasklist and taskkill to end a process without Task Manager.

Good habits from the first command

Walkthrough

Task 1: Windows Command Prompt

1Open cmd and get help

Log in to Win8.1, right-click Start > Command Prompt, and try both ways of getting help:

dir /?
help dir

2List your home folder

dir

You're in C:\Users\sysadmin. Open File Explorer, go to C:\Users\sysadmin, and compare. It's the same set of folders, shown two ways.

3Move around

cd
cd Documents
cd
dir
cls
cd ..

cd alone prints where you are. In the dir listing, . is the current folder and .. is the parent. cls clears the screen.

4Make folders

md CLI
cd CLI
md Meeting
dir

5Create a file by redirection

date

date shows the date and waits for a new one. Press Ctrl+C to cancel. Now send its output to a file:

date>calendar

Press Enter once more to get the prompt back. Then:

dir
type calendar
Where people get stuck

date>calendar looks frozen because date is still waiting for input. It isn't; press Enter.

6Copy, rename, and delete

copy calendar calendar.bk
move calendar.bk trash
del trash
rd Meeting
dir
exit

move also renames a file when the destination is a new name in the same folder.

ScreenshotThe cmd window showing the CLI folder listing after the copy, move, and delete commands.

Task 2: Elevated prompt and processes (Win8.1)

7Open Command Prompt (Admin)

Right-click Start > Command Prompt (Admin) and accept UAC. The title bar says Administrator, and you start in C:\WINDOWS\system32.

8Use a wildcard and launch a program

dir notepad*
notepad.exe

The * matches anything, so notepad* finds every file starting with "notepad".

9List and end a process

tasklist
taskkill /IM notepad.exe
taskkill /?
tasklist

Find notepad.exe in the first list and note its PID and Mem Usage. After taskkill, it's gone from the second list. /IM means "image name".

ScreenshotThe tasklist and taskkill output showing notepad.exe ended.

10Sign out from the command line

shutdown /?
shutdown /l

Task 3: Linux shell (Lubuntu)

11Open the terminal and look around

Sign in to Lubuntu, open Menu > System Tools > LXTerminal, and run:

pwd
ls
ls -l

pwd prints the working directory (/home/sysadmin, shown as ~). ls -l adds permissions, owner, size, and date.

12Move into Documents

cd Documents
pwd
ls

13Make folders and a file

mkdir Test
ls
cd Test
pwd
mkdir Redirect
ls -l > example
ls
cat example

> sends the output of ls -l into a file named example; cat displays it.

The shell doesn't confirm

Most Linux commands print nothing when they succeed. No message means it worked. Check with ls.

14Copy, rename, and delete files

cp example example.bk
cat example.bk
mv example.bk sample
ls
rm sample
rm example
ls

15Remove a folder that isn't empty

cd ..
rmdir Test
ls Test
rm -r Test
ls
exit

rmdir refuses because Test still contains Redirect. rm -r removes a folder and everything in it.

Be careful with rm -r

Linux has no Recycle Bin from the shell. rm -r deletes immediately and permanently, and with sudo it can delete system files.

ScreenshotThe terminal showing rmdir failing, then rm -r succeeding.

The lab is complete.

Professional habit

Before a command that deletes or overwrites, run dir or ls first so you know exactly what it will act on.

On the A+ exams

Core 2: Operating Systems

Core 2 (220-1202) expects you to know Windows commands (cd, dir, md, rmdir, copy, xcopy, robocopy, del, tasklist, taskkill, shutdown, chkdsk, format, diskpart, sfc, gpupdate, gpresult, winver, net) and Linux commands (ls, pwd, cd, mv, cp, rm, mkdir, chmod, chown, sudo, su, apt, dnf, grep, find, ps, top, ip, df, man, nano, cat), and when an elevated prompt is required.

High-yield facts

  • command /? is help in cmd; man command in Linux.
  • taskkill /IM name /F force-ends a process by name; /PID by number.
  • robocopy is the most robust Windows copy tool; /mir mirrors.
  • Linux is case-sensitive; Windows isn't.
  • rm -r deletes directories recursively and permanently.
  • sudo runs one command as root; an elevated prompt does the same job in Windows.

Check yourself

1. Which cmd command shows your current folder, and what's the Linux equivalent?

cd with nothing after it in cmd; pwd in Linux.

2. Write the command that ends every running copy of chrome.exe immediately.

taskkill /IM chrome.exe /F

3. You run rmdir Projects in Linux and get "Directory not empty." What do you run instead?

rm -r Projects (after checking its contents with ls Projects).

4. What's the difference between > and >>?

> replaces the file's contents with the output; >> adds the output to the end of the file.

5. Why did you open Command Prompt (Admin) for some tasks?

Some commands change system settings or other users' processes, which Windows allows only from an elevated prompt, even when you're signed in as an administrator.
