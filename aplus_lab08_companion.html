Command Line: Windows & Linux

When the desktop won't load or you're working remotely, the command line is how you get things done. You will navigate, create, copy, rename, and delete files and folders in the Windows Command Prompt and the Linux terminal, and manage processes from an elevated prompt.

Why this lab matters

Every technician needs the command line. It works in Windows Recovery when the desktop won't start, over a remote shell, in scripts (Lab 17), and on the Linux servers and appliances you'll meet sooner than you expect.

This lab does the same set of jobs twice, once in Windows cmd and once in the Linux shell: find out where you are, list what's there, move around, make folders and files, copy, rename, and delete. Doing them side by side is the fastest way to learn both, because the ideas are identical and only the command names change.

You'll also see why some commands need an elevated (administrator) prompt, and use tasklist and taskkill to end a process without Task Manager.

Walkthrough

Task 1: Windows Command Prompt

1Open cmd and get help

Log in to Win8.1, right-click Start > Command Prompt, and try both ways of getting help:

dir /?
help dir

2List your home folder

dir

You're in C:\Users\sysadmin. Open File Explorer, go to C:\Users\sysadmin, and compare. It's the same set of folders, shown two ways.

3Move around

cd
cd Documents
cd
dir
cls
cd ..

cd alone prints where you are. In the dir listing, . is the current folder and .. is the parent. cls clears the screen.

4Make folders

md CLI
cd CLI
md Meeting
dir

5Create a file by redirection

date

date shows the date and waits for a new one. Press Ctrl+C to cancel. Now send its output to a file:

date>calendar

Press Enter once more to get the prompt back. Then:

dir
type calendar
Where people get stuck

date>calendar looks frozen because date is still waiting for input. It isn't; press Enter.

6Copy, rename, and delete

copy calendar calendar.bk
move calendar.bk trash
del trash
rd Meeting
dir
exit

move also renames a file when the destination is a new name in the same folder.

ScreenshotThe cmd window showing the CLI folder listing after the copy, move, and delete commands.

Task 2: Elevated prompt and processes (Win8.1)

7Open Command Prompt (Admin)

Right-click Start > Command Prompt (Admin) and accept UAC. The title bar says Administrator, and you start in C:\WINDOWS\system32.

8Use a wildcard and launch a program

dir notepad*
notepad.exe

The * matches anything, so notepad* finds every file starting with "notepad".

9List and end a process

tasklist
taskkill /IM notepad.exe
taskkill /?
tasklist

Find notepad.exe in the first list and note its PID and Mem Usage. After taskkill, it's gone from the second list. /IM means "image name".

ScreenshotThe tasklist and taskkill output showing notepad.exe ended.

10Sign out from the command line

shutdown /?
shutdown /l

Task 3: Linux shell (Lubuntu)

11Open the terminal and look around

Sign in to Lubuntu, open Menu > System Tools > LXTerminal, and run:

pwd
ls
ls -l

pwd prints the working directory (/home/sysadmin, shown as ~). ls -l adds permissions, owner, size, and date.

12Move into Documents

cd Documents
pwd
ls

13Make folders and a file

mkdir Test
ls
cd Test
pwd
mkdir Redirect
ls -l > example
ls
cat example

> sends the output of ls -l into a file named example; cat displays it.

The shell doesn't confirm

Most Linux commands print nothing when they succeed. No message means it worked. Check with ls.

14Copy, rename, and delete files

cp example example.bk
cat example.bk
mv example.bk sample
ls
rm sample
rm example
ls

15Remove a folder that isn't empty

cd ..
rmdir Test
ls Test
rm -r Test
ls
exit

rmdir refuses because Test still contains Redirect. rm -r removes a folder and everything in it.

Be careful with rm -r

Linux has no Recycle Bin from the shell. rm -r deletes immediately and permanently, and with sudo it can delete system files.

ScreenshotThe terminal showing rmdir failing, then rm -r succeeding.

The lab is complete.

The commands below will allow you to receive help on using the parameters for the dir command. Both commands accomplish the same objective of receiving help. C:\Users\sysadmin> help dir When typing commands in the command prompt, typically at the end of every typed command you press the Enter key to initiate the command. Also, if you accidentally misspelled a command, as a shortcut, you can press the up arrow to bring back the previous commands you've entered. To get help at any place in the command prompt, type help and a list of all available commands will display. If you need help with a specific command type <command> /?.

8 In the File Explorer window, type C:\Users\sysadmin in the search field, followed by pressing the Enter key in the address field.

    Task 2 - Navigating the Command Line Interface in Linux

    Task 2.1 - Using the CLI in Lubuntu

    1 Access the Lubuntu system from the topology.

    2 Sign in as the sysadmin using Train1ng$ as the password.

    3 Click on the Menu button located on the bottom taskbar and navigate to System Tools > LXTerminal to open the terminal window, which in comparison to Windows, is similar to the command prompt with regards to using a command-line interface.

    4 Leave the terminal open to continue with the next task. 2.1.1 View the Contents of a Directory In Linux, when you open the CLI, the prompt indicates the current working directory of the file system, similar to Windows. It is very important to know the directory in which you are currently working.

    1 At the terminal, type the command below, followed by pressing the Enter key. This command displays the current working directory path. When typing commands in the terminal, typically at the end of every typed command you press the Enter key to initiate the command. Also, if you accidentally misspelled a command, as a shortcut, you can press the up arrow to bring back the previous commands you've entered. To get help at any place in the terminal, type help and a list of all available commands will display. If you need help for a specific command type man <command>.

    sysadmin@lubuntu:~$ pwd

    2 Type the ls command, followed by pressing the Enter key. This command displays a list of files and directories inside the current working directory.

    sysadmin@lubuntu:~$ ls

    3 Enter the command below to display a detailed list of files and directories. sysadmin@lubuntu:~$ ls -l

    4 Leave the terminal open to continue with the next task.

    2.1.2        Working with Directories

    1 At the terminal prompt, enter the command below to move into the Documents directory. The cd command allows you to change between directories. sysadmin@lubuntu:~$ cd Documents

    2 Enter the pwd command to identify your current working directory. Notice you are now in the /home/sysadmin/Documents directory.

    sysadmin@lubuntu:~/Documents$ pwd

    3 Enter the ls command to view the contents of the Documents directory. Notice no files or directories are present here.

    sysadmin@lubuntu:~/Documents$ ls

    4 Leave the terminal open to continue with the next task. 2.1.3 Creating Directories and Files

    1 At the terminal, enter the mkdir command below to create a new directory called Test in the current working directory. The command-line is not interactive for many commands. If you do not get an error message, you may assume your command succeeded. You will not be asked if you are sure you want to continue or be given feedback about the action taken, so it is important to verify the results of your actions.

    sysadmin@lubuntu:~/Documents$ mkdir Test

    2 Verify that the new Test directory exists by entering the ls command.

    sysadmin@lubuntu:~/Documents$ ls

    3 Enter the cd command below to change to the Test directory.

    sysadmin@lubuntu:~/Documents$ cd Test

    4 Enter the pwd command to verify your current working directory.

    sysadmin@lubuntu:~/Documents/Test$ pwd

    5 Enter the command below to create a new Redirect directory in Test.

    sysadmin@lubuntu:~/Documents/Test$ mkdir Redirect

    6 Enter the ls command to verify that the Redirect directory has been successfully created.

    sysadmin@lubuntu:~/Documents/Test$ ls

    7 Now, it's time to create files. The first method you will use to create a file is to send the output of a command to a file. This is called redirection, and you use the greater than ">" or pipe "|" redirector symbol to redirect output from one command into another. This command also lets you chain commands together into a more robust command. Enter the command below to redirect the output from the ls command to a file named example.

    sysadmin@lubuntu:~/Documents/Test$ ls -l > example

    8 Verify that the example file exists by entering the ls command.

    sysadmin@lubuntu:~/Documents/Test$ ls

    9 View the contents of the example file by using the cat command. Enter the command below. Notice that the output from the ls -l command is copied in this file.

    sysadmin@lubuntu:~/Documents/Test$ cat example

    10 Make a copy of the example file and call it example.bk. Enter the command below.

    sysadmin@lubuntu:~/Documents/Test$ cp example example.bk

    11 Verify that the file was created successfully using the ls command.

    sysadmin@lubuntu:~/Documents/Test$ ls

    12 Verify that the contents of the file were copied successfully by using the cat command. Enter the command below.

    sysadmin@lubuntu:~/Documents/Test$ cat example.bk

    13 Enter the mv command below to rename the example.bk file to sample. Even though the mv command is used to move files, it can also be used to rename files.

    sysadmin@lubuntu:~/Documents/Test$ mv example.bk sample

    14 Verify that the file has been renamed successfully by entering the ls command.

    sysadmin@lubuntu:~/Documents/Test$ ls

    15 Enter the command below to delete the sample file.

    sysadmin@lubuntu:~/Documents/Test$ rm sample

    16 Remove the example file using the rm command.

    sysadmin@lubuntu:~/Documents/Test$ rm example

    17 Enter the ls command to verify that both the example and sample files have been removed from the Test directory.

    sysadmin@lubuntu:~/Documents/Test$ ls

    18 Use the cd command to go back to the Documents directory as your working directory. sysadmin@lubuntu:~/Documents/Test$ cd ..

    19 Remove the Test directory by entering the command below.

    sysadmin@lubuntu:~/Documents$ rmdir Test

    20 Notice the message that appears. Enter the ls command below to see what other objects are in the Test directory that are preventing us from being able to delete the directory.

    sysadmin@lubuntu:~/Documents$ ls Test

    21 Notice there is another directory that we created called Redirect. To remove a directory with subdirectories, we need to use additional parameters along with the rm command. Enter the command below. The -r option for the rm command is used to remove directories and their contents recursively.

    sysadmin@lubuntu:~/Documents$ rm -r Test

    On the A+ exams

    Core 2: Operating Systems

    Core 2 (220-1202) expects you to know Windows commands (cd, dir, md, rmdir, copy, xcopy, robocopy, del, tasklist, taskkill, shutdown, chkdsk, format, diskpart, sfc, gpupdate, gpresult, winver, net) and Linux commands (ls, pwd, cd, mv, cp, rm, mkdir, chmod, chown, sudo, su, apt, dnf, grep, find, ps, top, ip, df, man, nano, cat), and when an elevated prompt is required.

    High-yield facts

    • command /? is help in cmd; man command in Linux.
    • taskkill /IM name /F force-ends a process by name; /PID by number.
    • robocopy is the most robust Windows copy tool; /mir mirrors.
    • Linux is case-sensitive; Windows isn't.
    • rm -r deletes directories recursively and permanently.
    • sudo runs one command as root; an elevated prompt does the same job in Windows.

    Check yourself

    1. Which cmd command shows your current folder, and what's the Linux equivalent?

    cd with nothing after it in cmd; pwd in Linux.

    2. Write the command that ends every running copy of chrome.exe immediately.

    taskkill /IM chrome.exe /F

    3. You run rmdir Projects in Linux and get "Directory not empty." What do you run instead?

    rm -r Projects (after checking its contents with ls Projects).

    4. What's the difference between > and >>?

    > replaces the file's contents with the output; >> adds the output to the end of the file.

    5. Why did you open Command Prompt (Admin) for some tasks?

    Some commands change system settings or other users' processes, which Windows allows only from an elevated prompt, even when you're signed in as an administrator.
