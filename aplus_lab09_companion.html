Why this lab matters

A lot of help desk work is configuration: "my screen is too small," "my laptop goes to sleep during presentations," "I can't see the file extension," "is this PC up to date?" Each answer lives in a specific Settings page or Control Panel applet, and knowing where is what makes you fast.

The lab also touches two settings with security weight. Show file extensions helps users spot a file named invoice.pdf.exe for what it is. User Account Control decides how loudly Windows warns before a program makes system changes. Both appear on the exam as security best practices, not just preferences.

Microsoft retired Internet Explorer in 2022. The Internet Options applet you'll use still matters: Windows uses it for proxy settings, security zones, and some app connections, and Edge reads several of these settings.

Walkthrough

Task 1: Settings

1Check the Windows version and build (Win10)

Log in to Win10. Right-click Start > Settings > System, scroll down the left pane, and click About. Under Windows specifications, note the Version and OS Build. They tell you which feature update is installed.

ScreenshotThe About page showing Version and OS Build.

The same information from the Run box or a prompt
winver
systeminfo | findstr /B /C:"OS Name" /C:"OS Version"

2Change the display resolution (Win8.1)

Log in to Win8.1. Open Start > PC settings > PC and devices > Display. The resolution is 1024 x 768. Move the slider to 1280 x 768, click Apply, then Keep changes. The screen gets wider. Change it back to 1024 x 768.

Why Windows asks you to keep changes

If a resolution doesn't display, you can't see the button. Windows reverts automatically after about 15 seconds unless you confirm.

Task 2: Power Options (Win8.1)

3Choose a plan

Go back to PC settings and click Control Panel at the bottom of the left pane. Set View by to Small icons and open Power Options. Select Balanced (recommended), then click Change plan settings > Change advanced power settings.

4Change the advanced settings

Click Change settings that are currently unavailable, then set:

SettingValue
Hard disk > Turn off hard disk after45 minutes
Sleep > Sleep afterNever (type 0)
USB settings > USB selective suspend settingDisabled
Display > Turn off display after30 minutes

Click OK and close the plan window.

ScreenshotThe Power Options advanced settings window with your changes.

Task 3: Internet Options (Win8.1)

5Clear browsing data

Right-click Start > Control Panel > Internet Options. Under Browsing history, click Delete. Make sure Tracking Protection, ActiveX Filtering and Do Not Track is unchecked, leave the other defaults, and click Delete.

6Change history settings

Click Settings under Browsing history. Select Every time I visit the webpage. On the History tab, set Days to keep pages in history to 10. Click OK.

7Review security zones

Open the Security tab. Select Internet and click Custom level to see the many settings you can restrict, then Cancel.

Select Trusted sites > Sites, uncheck Require server verification (https:) for all sites in this zone, enter the site address the lab gives you, click Add, then Close. Click Custom level for Trusted sites: most options are enabled, because you trust these sites. Click Cancel.

ScreenshotThe Trusted sites window with a site added.

8Block pop-ups and third-party cookies

On the Privacy tab, make sure Turn on Pop-up Blocker is checked, then click Advanced. Check Override automatic cookie handling and choose Block for Third-party Cookies. Click OK twice.

ScreenshotThe Advanced Privacy Settings window blocking third-party cookies.

Task 4: Personalization (Win8.1)

9Apply a high contrast theme

In Control Panel, open Personalization and click High Contrast #1. Then click Desktop Background, pick a color, and click Save changes. Close the window.

Task 5: Hidden files and extensions (Win8.1)

10Show hidden items

Open File Explorer > Local Disk (C:). On the View tab, check Hidden items. The hidden ProgramData folder appears. Open Program Files > TightVNC and look at the file names.

11Show file extensions

Open Control Panel > Folder Options > View and uncheck Hide extensions for known file types. Click OK. Back in the TightVNC folder, names now end in .exe, .txt, and so on.

ScreenshotThe TightVNC folder showing file extensions.

Task 6: User Account Control (Win8.1)

12Raise UAC to Always notify

Open Control Panel > Action Center > Change User Account Control settings. Drag the slider to the top, Always notify, and click OK. Accept the UAC prompt.

ScreenshotThe UAC settings slider at Always notify.

The lab is complete.

    Power plans and states

    TermMeaning
    Balanced / Power saver / High performanceBuilt-in plans trading performance against battery life
    Sleep (S3)RAM stays powered; fast to resume
    Hibernate (S4)RAM saved to hiberfil.sys, PC powers off; slower to resume, no battery used
    Hybrid sleepSleep plus a hibernate file, for desktops
    Fast startupShutdown saves the kernel to disk for faster boot. Can hide hardware changes and block firmware key presses.
    USB selective suspendPowers down idle USB devices; disable it if devices disconnect randomly
    List plans, show the active one, and report battery or energy problems
powercfg /list
powercfg /getactivescheme
powercfg /batteryreport
powercfg /energy

    LevelBehavior

    Same, without dimming the desktopPrompt appears on the normal desktop (less protected)

    Professional habit

    Change scaling before resolution. Lowering resolution blurs an LCD; scaling makes text bigger at the panel's native resolution.

    On the A+ exams

    Core 2: Operating SystemsCore 2: Security

    Core 2 (220-1202) covers Windows Settings and Control Panel utilities by name and .cpl shortcut, power options (sleep, hibernate, fast startup, USB selective suspend, power plans), display settings, File Explorer options, Internet Options, and UAC as a security setting.

    High-yield facts

    • appwiz.cpl, ncpa.cpl, sysdm.cpl, inetcpl.cpl, powercfg.cpl, desk.cpl, firewall.cpl, mmsys.cpl.
    • Hibernate saves RAM to disk and powers off; sleep keeps RAM powered.
    • Disable USB selective suspend when USB devices drop out.
    • Showing file extensions is a security best practice.
    • UAC's default is "Notify only when apps try to make changes"; Always notify is the most secure.
    • winver shows the version and build.

    Check yourself

    1. A user's laptop battery is dead every morning even though they closed the lid. Which power setting helps?

    Set the lid action or sleep to Hibernate (or hybrid sleep), which saves to disk and uses no battery overnight.

    2. A USB barcode scanner keeps disconnecting after a few minutes of inactivity. What do you change?

    Disable USB selective suspend in the power plan's advanced settings.

    3. Why turn off "Hide extensions for known file types" on a user's PC?

    So the real file type shows. A file named invoice.pdf.exe would otherwise look like invoice.pdf.

    4. What's the most secure UAC setting, and what does it add over the default?

    Always notify. It also prompts when you change Windows settings yourself, not just when apps make changes.

    5. Which command opens Internet Options directly?

    inetcpl.cpl
