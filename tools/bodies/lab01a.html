Why this lab matters

Every PC runs code before the operating system starts. That code is the firmware: the older BIOS or the newer UEFI. It tests the hardware at power-on (the POST), decides which drive to boot from, and holds settings such as boot passwords, Secure Boot, and the TPM. When a PC won't boot from a USB stick, won't accept a Windows 11 upgrade, or keeps forgetting the date, the fix is often in firmware setup.

Once Windows is running, Device Manager is the technician's first stop for hardware. It shows every device Windows knows about, flags the ones with problems, and lets you update, roll back, disable, or uninstall the driver that runs each one.

By the end you should be able to get into firmware setup two different ways, change the boot order safely, and read a device's driver, events, and resources in Device Manager.

Walkthrough

Task 1: Firmware setup (BIOS and UEFI)

1Get into BIOS setup on Win7

On the Win7 login screen, click the arrow beside Shut down and choose Restart. As soon as the screen goes dark, press F2 repeatedly until the PhoenixBIOS Setup Utility opens.

Where people get stuck

The VM console has to have keyboard focus, or your F2 presses go nowhere. Click inside the console window before you click Restart. If Windows starts loading, let it finish, restart, and try again.

2Tour the menus

There's no mouse in this utility. Use the arrow keys to move between tabs, Enter to select, and the key guide along the bottom of the screen for everything else.

TabWhat it controls
MainSystem date and time, basic configuration, installed memory
AdvancedPorts, interrupts, I/O device configuration
SecuritySupervisor and user passwords, boot-sector protection
BootThe order the firmware tries boot devices
ExitSave changes, discard changes, or load defaults

Look, but don't change anything except the boot order. A wrong firmware setting can stop the machine from booting.

3Change the boot order

Open the Boot tab. Highlight Removable Devices and press - to move it down one place so Hard Drive is first. In this utility, + moves an item up and - moves it down.

ScreenshotThe Boot tab with Hard Drive at the top of the list.

Why a tech does this

Putting the internal drive first stops the PC from trying to boot from a USB stick someone left plugged in. When you need to boot from USB to reinstall or repair, most PCs have a one-time boot menu (often F12) so you don't have to change the order at all.

4Save and exit

Go to the Exit tab, highlight Exit Saving Changes, press Enter, and confirm with Yes. Many setup utilities also accept F10 as save and exit. Win7 restarts with the new order.

5Reach UEFI from inside Windows 10

Log in to Win10 as sysadmin. Open Start > Settings > Update & Security > Recovery, and under Advanced startup click Restart now. When the blue Choose an option screen appears, click Troubleshoot > Advanced options.

On a UEFI PC you would see a UEFI Firmware Settings tile here, which restarts straight into setup. This VM uses legacy BIOS, so the tile is missing. That is expected.

ScreenshotThe Advanced options screen showing the tiles that are available.

The same menu can be reached from the command line. Run these in an elevated Command Prompt on a real PC:

:: Restart into the Advanced startup (Choose an option) menu
shutdown /r /o /t 0

:: Restart straight into UEFI firmware setup (UEFI PCs only)
shutdown /r /fw /t 0

You can also hold Shift while you click Restart on the Start menu or login screen.

6Back out and boot normally

Click the back arrow until you return to Choose an option, then click Continue to start Windows.

Task 2: Device Manager

7Open Device Manager from Control Panel (Win7)

Log in to Win7. Open Start > Control Panel, set View by to Small icons, and click Device Manager.

8Show hidden devices and read the hardware

Open the View menu and choose Show hidden devices. That adds non-Plug and Play drivers, low-level system drivers, and devices that are no longer connected. Expand Processors to see the CPU model and speed, then expand Mice and other pointing devices.

ScreenshotDevice Manager with hidden devices shown and Processors expanded.

9Inspect a driver, and don't roll it back

Right-click VMware Pointing Device and choose Properties. On the Driver tab, click Roll Back Driver, read the prompt, and click No.

ScreenshotThe Driver tab or the Roll Back confirmation prompt.

Then open the Resources tab. It lists the I/O ranges and IRQ the device uses, and a Conflicting device list at the bottom. Don't change these settings. Close the windows when you're done.

10Open Device Manager with Run (Win10)

Switch to Win10. Right-click Start, choose Run, and enter:

devmgmt.msc

11Read a device's history in the Events tab

Expand Display adapters, right-click the adapter, and choose Properties. Windows 10 adds an Events tab that Windows 7 doesn't have. It lists when the device was installed, configured, started, or updated. Click View All Events to open Event Viewer, then look at the Details tab.

ScreenshotThe Events tab or the Event Viewer details for the display adapter.

Close Event Viewer and the Properties window. The lab is complete.

BIOS compared with UEFI

Legacy BIOSUEFI
InterfaceText menus, keyboard onlyOften graphical, with mouse support
Boot disk formatMBR: disks up to about 2 TB, four primary partitionsGPT: very large disks, up to 128 partitions in Windows
SecuritySetup and boot passwordsAdds Secure Boot, which blocks unsigned boot loaders
Windows 11Not supportedRequired, with Secure Boot capability and TPM 2.0
Older OS supportNativeThrough CSM (Compatibility Support Module) if the board offers it

Firmware settings you'll be asked about

  • Boot options: boot order, one-time boot menu, USB and network (PXE) boot.
  • Passwords: a supervisor (administrator) password protects setup; a user or power-on password is needed to boot at all.
  • Secure Boot and TPM: both needed for Windows 11, and the TPM is used by BitLocker (Lab 15).
  • Virtualization: Intel VT-x or AMD-V must be on for Hyper-V (Lab 16).
  • Hardware monitoring: CPU temperature, fan speeds, and voltages.
  • USB permissions: enable or disable ports, often for security.

Getting into setup

The key depends on the board maker, not Windows. Watch the boot screen or check the manual. Common setup keys are Del, F2, F10, F1, and Esc. One-time boot menus are often F12, F11, F9, or F8.

High-yield facts

  • The setup key comes from the board maker, not the operating system.
  • UEFI pairs with GPT disks; legacy BIOS pairs with MBR. Windows 11 requires UEFI, Secure Boot capability, and TPM 2.0.
  • Supervisor password protects setup; user or power-on password protects booting.
  • Wrong time and lost settings after power-off point to a dead CMOS battery.
  • devmgmt.msc opens Device Manager. A yellow "!" means a problem; a down arrow means disabled.
  • Roll Back Driver is the first fix when a device fails right after a driver update.

Check yourself

1. A user's PC keeps trying to boot from a USB drive left in the port. What setting do you change, and where?

The boot order, in BIOS/UEFI setup. Put the internal drive first. For the rare times you need USB boot, use the one-time boot menu instead.

2. You're upgrading a PC to Windows 11 and the check fails on Secure Boot. The disk is MBR. What has to change?

Secure Boot needs UEFI boot mode, and UEFI boots from GPT disks. Convert the disk to GPT (Windows includes the mbr2gpt tool), switch firmware to UEFI, then enable Secure Boot.

3. A network adapter stopped working right after a driver update. What's the fastest fix in Device Manager?

Properties > Driver > Roll Back Driver, which restores the previous driver version.

4. Why might the UEFI Firmware Settings tile be missing from Advanced options?

The PC is running in legacy BIOS mode (or Windows was installed in legacy mode). The tile appears only on UEFI installations.

5. What does Show hidden devices add to the Device Manager list?

Non-Plug and Play drivers, low-level system drivers, drivers installed by other software, and devices that were installed but aren't connected now.
