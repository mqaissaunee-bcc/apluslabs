== overview | Why this lab matters
Every technician needs the command line. It works in Windows Recovery when the desktop won't start, over a remote shell, in scripts (Lab 17), and on the Linux servers and appliances you'll meet sooner than you expect.
This lab does the same set of jobs twice, once in **Windows cmd** and once in the **Linux shell**: find out where you are, list what's there, move around, make folders and files, copy, rename, and delete. Doing them side by side is the fastest way to learn both, because the ideas are identical and only the command names change.
You'll also see why some commands need an **elevated** (administrator) prompt, and use `tasklist` and `taskkill` to end a process without Task Manager.

== walkthrough | Walkthrough
## Task 1: Windows Command Prompt <<1.1.1–1.1.3>>
@@ Win8.1
### Open cmd and get help
Open the **Win8.1** console, click the splash screen, and sign in as `sysadmin` with `Train1ng$`. Right-click **Start** and choose **Command Prompt**. Try both ways of getting help:
```C:\Users\sysadmin>
dir /?
help dir
```
!tip Two habits from the PDF | Press [[Enter]] after every command, and press [[Up]] to bring back a command you mistyped. `help` alone lists every command; `command /?` gives help for one.
### List your home folder
```C:\Users\sysadmin>
dir
```
You're in `C:\Users\sysadmin`. Open **File Explorer** from the taskbar, type `C:\Users\sysadmin` in the address bar, and press [[Enter]]. It's the same set of folders, shown two ways.
### Move around
Print where you are, list the folder, and move into **Documents**:
```C:\Users\sysadmin>
cd
dir
cd Documents
```
The prompt changes to show the new location. Print it, list it (note `.` for the current folder, `..` for the parent, and the **Backup** folder), clear the screen, and go back up:
```C:\Users\sysadmin\Documents>
cd
dir
cls
cd ..
```
In File Explorer, double-click **Documents** and compare: the same **Backup** folder is there.
### Make folders
```C:\Users\sysadmin>
md CLI
dir
cd CLI
>> C:\Users\sysadmin\CLI>
cd
md Meeting
dir
```
### Create a file by redirection
```C:\Users\sysadmin\CLI>
date
```
`date` shows the date and waits for a new one. Press [[Ctrl]]+[[C]] to cancel. Now send its output to a file named `calendar`:
```C:\Users\sysadmin\CLI>
date>calendar
```
Press [[Enter]] a second time to get the prompt back. Then check the file and read it:
```C:\Users\sysadmin\CLI>
dir
type calendar
```
!stuck Where people get stuck | `date>calendar` looks frozen because `date` is still waiting for input. It isn't; press [[Enter]].
### Copy, rename, and delete
Check with `dir` after each change, as the PDF does:
```C:\Users\sysadmin\CLI>
copy calendar calendar.bk
dir
move calendar.bk trash
dir
del trash
dir
rd Meeting
dir
exit
```
`move` also renames a file when the destination is a new name in the same folder.
!shot The cmd window showing the CLI folder listing after the copy, move, and delete commands.
## Task 2: Elevated prompt and processes <<1.1.4>>
@@ Win8.1
### Open Command Prompt (Admin)
Right-click **Start > Command Prompt (Admin)** and click **Yes** at UAC. The title bar says **Administrator**, and you start in `C:\WINDOWS\system32`. List it (there's a lot of output):
```C:\WINDOWS\system32>
dir
```
### Use a wildcard and launch a program
```C:\WINDOWS\system32>
dir notepad*
notepad.exe
```
The `*` matches anything, so `notepad*` finds every file starting with "notepad". Notepad opens because `notepad.exe` is in the current folder.
### List and end a process
Change focus back to the prompt:
```C:\WINDOWS\system32>
tasklist
taskkill /IM notepad.exe
taskkill /?
tasklist
```
Find **notepad.exe** in the first list and note its **PID** and **Mem Usage**. `/IM` means "image name". After `taskkill`, it's gone from the second list.
!shot The tasklist and taskkill output showing notepad.exe ended.
### Sign out from the command line
```C:\WINDOWS\system32>
shutdown /?
shutdown /l
```
## Task 3: Linux shell <<2.1–2.1.3>>
@@ Lubuntu
### Open the terminal and look around
Open the **Lubuntu** console and sign in as `sysadmin` with `Train1ng$`. Click **Menu > System Tools > LXTerminal**, then run:
```sysadmin@lubuntu:~$
pwd
ls
ls -l
```
`pwd` prints the working directory (`/home/sysadmin`, shown as `~`). `ls -l` adds permissions, owner, size, and date. For help in the terminal use `help`, or `man command` for one command.
### Move into Documents
```sysadmin@lubuntu:~$
cd Documents
>> sysadmin@lubuntu:~/Documents$
pwd
ls
```
### Make folders and a file
```sysadmin@lubuntu:~/Documents$
mkdir Test
ls
cd Test
>> sysadmin@lubuntu:~/Documents/Test$
pwd
mkdir Redirect
ls
ls -l > example
ls
cat example
```
`>` sends the output of `ls -l` into a file named `example`; `cat` displays it.
!tip The shell doesn't confirm | Most Linux commands print nothing when they succeed. No message means it worked. Check with `ls`.
### Copy, rename, and delete files
```sysadmin@lubuntu:~/Documents/Test$
cp example example.bk
ls
cat example.bk
mv example.bk sample
ls
rm sample
rm example
ls
```
### Remove a folder that isn't empty
```sysadmin@lubuntu:~/Documents/Test$
cd ..
>> sysadmin@lubuntu:~/Documents$
rmdir Test
ls Test
rm -r Test
ls
exit
```
`rmdir` refuses because `Test` still contains `Redirect`. `rm -r` removes a folder and everything in it.
!stuck Be careful with rm -r | Linux has no Recycle Bin from the shell. `rm -r` deletes immediately and permanently, and with `sudo` it can delete system files.
!shot The terminal showing rmdir failing, then rm -r succeeding.
The lab is complete.

== reference | Reference: Windows and Linux commands
### The same job in both shells
| Job | Windows cmd | Linux |
| Where am I? | `cd` | `pwd` |
| List files | `dir` | `ls`, `ls -l`, `ls -a` |
| Change folder | `cd folder`, `cd ..`, `cd \` | `cd folder`, `cd ..`, `cd ~` |
| Make a folder | `md` or `mkdir` | `mkdir` (`mkdir -p a/b/c` for nested) |
| Remove an empty folder | `rd` or `rmdir` | `rmdir` |
| Remove a folder and contents | `rd /s` | `rm -r` |
| Copy | `copy` (files), `xcopy`, `robocopy` (folders) | `cp`, `cp -r` |
| Move or rename | `move`, `ren` | `mv` |
| Delete a file | `del` | `rm` |
| Show a file | `type` | `cat`, `less` |
| Clear the screen | `cls` | `clear` |
| Help | `command /?`, `help command` | `man command`, `command --help` |
| Running processes | `tasklist` | `ps aux`, `top` |
| End a process | `taskkill /IM name` or `/PID n` | `kill PID`, `pkill name` |
| Find text | `findstr` | `grep` |
| Network config | `ipconfig` | `ip addr` (`ifconfig` on older systems) |
| Run as admin | Elevated prompt | `sudo command` |
### Redirection and pipes (both shells)
| Symbol | Does | Example |
| `>` | Send output to a file, replacing it | `dir > list.txt` |
| `>>` | Append output to a file | `echo done >> log.txt` |
| `\|` | Feed one command's output to the next | `tasklist \| findstr notepad` |
| `*` | Wildcard, any characters | `dir *.txt`, `ls *.txt` |
### More Windows commands on the exam
| Command | Does |
| `robocopy src dst /e` | Robust folder copy with retries; `/mir` mirrors |
| `xcopy src dst /s /e` | Copies folders and subfolders |
| `chkdsk C: /f` | Checks and fixes file system errors (`/r` also finds bad sectors) |
| `format D: /fs:ntfs` | Formats a volume |
| `diskpart` | Interactive disk and partition tool |
| `sfc /scannow` | Repairs Windows system files (Lab 12) |
| `gpupdate /force`, `gpresult /r` | Apply and show Group Policy |
| `winver` | Shows the Windows version |
| `shutdown /r /t 0`, `/s`, `/l`, `/a` | Restart, shut down, sign out, abort a pending shutdown |
### More Linux commands on the exam
| Command | Does |
| `sudo`, `su` | Run as root; switch user |
| `chmod`, `chown` | Change permissions and ownership |
| `apt`, `dnf` | Install software (Lab 13) |
| `nano`, `vi` | Edit text files |
| `df -h`, `du -sh` | Disk free space; folder size |
| `find / -name file` | Find files by name |
| `grep text file` | Search inside files |
| `ip addr`, `ping`, `dig` | Network info and tests |
| `passwd` | Change a password |

== stuck | Where people get stuck
| Problem | Why it happens | Fix |
| "is not recognized as an internal or external command" | Typo, or the program isn't in the PATH or current folder | Check spelling; `cd` to its folder or use the full path |
| `cd Documents` fails in Linux | Linux names are case-sensitive | Type `Documents` with a capital D, or press [[Tab]] |
| `cd` in cmd doesn't change drives | `cd` changes folders, not drives | Type the drive letter alone, like `D:`, or use `cd /d D:\folder` |
| A path with spaces fails | The space splits it into two arguments | Wrap it in quotes: `cd "Program Files"` |
| `rmdir` won't delete a folder | It isn't empty | Linux: `rm -r`. Windows: `rd /s` |
| Access denied in cmd | The command needs elevation | Open Command Prompt (Admin) |
| The prompt seems frozen | A command is waiting for input | Press [[Enter]] or [[Ctrl]]+[[C]] |

== on-the-job | On the job
| Situation | Command line approach |
| Windows won't boot to the desktop | Windows Recovery > Command Prompt: `chkdsk`, `sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows`, copy files off |
| A program hangs and Task Manager won't open | `tasklist`, then `taskkill /IM name.exe /F` |
| Copy a user's profile to a new PC | `robocopy C:\Users\old D:\Backup\old /e` |
| Check disk space on a Linux server | `df -h` |
| Find which log mentions an error | `findstr /i error *.log` or `grep -i error *.log` |
!tip Professional habit | Before a command that deletes or overwrites, run `dir` or `ls` first so you know exactly what it will act on.

== exam | On the A+ exams
**Core 2 (220-1202)** expects you to know Windows commands (`cd`, `dir`, `md`, `rmdir`, `copy`, `xcopy`, `robocopy`, `del`, `tasklist`, `taskkill`, `shutdown`, `chkdsk`, `format`, `diskpart`, `sfc`, `gpupdate`, `gpresult`, `winver`, `net`) and Linux commands (`ls`, `pwd`, `cd`, `mv`, `cp`, `rm`, `mkdir`, `chmod`, `chown`, `sudo`, `su`, `apt`, `dnf`, `grep`, `find`, `ps`, `top`, `ip`, `df`, `man`, `nano`, `cat`), and when an elevated prompt is required.
### High-yield facts
- `command /?` is help in cmd; `man command` in Linux.
- `taskkill /IM name /F` force-ends a process by name; `/PID` by number.
- `robocopy` is the most robust Windows copy tool; `/mir` mirrors.
- Linux is case-sensitive; Windows isn't.
- `rm -r` deletes directories recursively and permanently.
- `sudo` runs one command as root; an elevated prompt does the same job in Windows.
