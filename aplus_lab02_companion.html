Why this lab matters

A technician's toolkit lives in a handful of Microsoft Management Console snap-ins plus Task Manager, Resource Monitor, and the Registry Editor. Knowing them by name and by shortcut is half the job: when a user calls, you need to open the right tool in seconds.

This lab covers the full range. MMC lets you build a custom console with only the snap-ins you need. Task Scheduler runs things automatically. Disk Management creates and formats volumes. Task Manager and Resource Monitor show what's using the machine and let you end what's stuck. Regedit edits the database behind almost every Windows setting.

The Registry task also teaches the rule that matters most: back up before you change anything, and know how to put it back.

Walkthrough

Task 1: Build an MMC console (Win7)

1Open an empty console

On Win7, open Start, type run, open Run, and enter:

mmc

Accept UAC. You get an empty Console1 window.

2Add three snap-ins

Choose File > Add/Remove Snap-in. Add Disk Management (choose This computer, then Finish), Event Viewer (Local computer), and Task Scheduler (Local computer). Click OK when all three are in Selected snap-ins.

ScreenshotThe Add or Remove Snap-ins window with all three snap-ins selected.

3Save the console

Choose File > Save As and save it as C:\Users\sysadmin\console. Windows adds the .msc extension. Close the console.

Task 2: Schedule a task (Win8.1)

4Add Task Scheduler to a console

On Win8.1, right-click Start > Run, enter mmc, and add the Task Scheduler snap-in for the local computer.

5Create the task

Select Task Scheduler in the left pane and choose Action > Create Task. Fill in:

TabSetting
GeneralName and Description: Notepad
TriggersNew > Begin the task: At log on
ActionsNew > Start a program > Browse to C:\windows\system32\notepad.exe

Click OK to close each window.

ScreenshotThe Create Task window, or the new Notepad task listed in Task Scheduler Library.

Create Task or Create Basic Task?

Create Basic Task is a wizard with fewer options. Create Task shows every tab (General, Triggers, Actions, Conditions, Settings), which is what you'll use for real work.

6Save, sign out, and test

Close the console and save it as C:\Users\sysadmin\console. Sign out from the Start screen and sign back in. Notepad should open on its own. Close it.

Task 3: Create volumes in Disk Management (Win7)

7Open your saved console

On Win7, open Start, type console.msc, and open it. Double-click Disk Management under Console Root.

8Create an NTFS volume

Right-click the Unallocated space on Disk 2 and choose New Simple Volume. Use these settings:

Wizard pageValue
Volume size2048 MB
Drive letterS
File systemNTFS, Volume label NTFS
Where people get stuck

Disk 2 is below the bottom of the window. Maximize the console or scroll the lower pane to find it. Right-click the black Unallocated bar, not the disk label on the left.

9Create a FAT32 volume

Right-click the remaining unallocated space (about 3 GB) and create a second simple volume: 2048 MB, drive letter L, file system FAT32, label FAT32.

ScreenshotDisk Management showing the new S: (NTFS) and L: (FAT32) volumes on Disk 2.

10Check in Computer

Close the console, saving it when asked, and double-click Computer on the desktop. You should see drives S: and L:.

Task 4: Task Manager

11End an application on Win7

Open Notepad. Right-click the taskbar and choose Start Task Manager. On the Applications tab, select Notepad and click End Task.

12Tour the Win7 tabs

Look at Processes (running programs and their memory), Services, Performance, Networking, and Users. Then on Processes, select taskmgr.exe and click End Process to close Task Manager itself.

Before you end a process

Ending a process discards unsaved work, and ending a system process can crash Windows. End only what you recognize, and prefer ending the app from the Applications or Processes view.

13Compare the newer Task Manager on Win8.1

On Win8.1, right-click the taskbar and choose Task Manager. Click More details. The Processes tab now combines apps and background processes with live CPU, memory, disk, and network columns. Note the newer App history and Startup tabs. Right-click Task Manager in the list and choose End task.

ScreenshotThe Win8.1 Task Manager in More details view.

Task 5: Resource Monitor (Win8.1)

14Open Resource Monitor

Open Task Manager again, click More details, go to Performance, and click Open Resource Monitor at the bottom. Look at each tab: Overview, CPU, Memory, Disk, and Network.

15Analyze a wait chain

On the CPU tab, find explorer.exe under Image, right-click it, and choose Analyze Wait Chain. A hung process shows in red; the wait chain names the process it's waiting on, which is often the real culprit.

ScreenshotThe Analyze Wait Chain window for explorer.exe.

Close all windows on Win8.1.

Task 6: Change and restore a Registry setting (Win7)

16Back up the Registry first

On Win7, open Start, type regedit, and open it. Accept UAC. Right-click Computer at the top of the tree, choose Export, and save as C:\Users\sysadmin\Documents\Reg-Backup.reg.

17Rename the Recycle Bin

Go to this key (on Windows 10 and 11 you can paste it into the address bar):

HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\CLSID\{645FF040-5081-101B-9F08-00AA002F954E}

(Default) reads (value not set). Double-click it, type Trash Bin as the Value data, and click OK. Right-click the desktop and choose Refresh. The Recycle Bin is now Trash Bin.

ScreenshotThe desktop showing Trash Bin, with Registry Editor open on the key.

18Export just that key

Right-click the {645FF040-...} key and choose Export. Save it to the Desktop as Trash Bin.

19Undo the change, then re-import it

Double-click (Default), delete the text, and click OK. Refresh the desktop: it says Recycle Bin again. Close Regedit, then double-click Trash Bin.reg on the desktop and click Yes through the warnings. Refresh again: the name is back to Trash Bin, restored from your export.

The lab is complete.

    Task 3 - Exploring Task Manager

    Task 3.1 - Accessing Task Manager in Windows 7

    1 While accessing the Win7 machine, click on the Start button and type notepad in the search. Click on Notepad to launch the application.

    2 Right-click in the Taskbar located at the bottom and select Start Task Manager. In the Application tab, a list of the programs currently running on your machine is displayed. Applications that run minimized in the System Tray (such as antivirus software) won't show up on this list. One useful function of this tab is that it can be used to exit programs that have stopped responding and that can no longer be closed normally.

    3 In the Windows Task Manager window, click on the Applications tab and then click on the Notepad application to highlight it, then click the End Task button to terminate the Notepad program.

    4 Notice the opened Notepad application is now closed. Click on the Processes tab, notice it displays a list of processes (instances of programs) running on the system. You can use the Processes tab to end a process, but this should be done with caution, as it could cause you to lose unsaved data. While ending the process of a nonresponsive application is sometimes the only way you can shut it down, be sure that you understand the purpose of the process you want to end. Terminating system processes may cause a system malfunction.

    5 Click on the Services tab to show all the support programs running in the background on the system. You can Stop or Start services from this tab. Also, you can check the resources being used by a service by right-clicking a running service and clicking Go To Process.

    6 Click on the Performance tab. This displays real-time monitoring of system performance.

    7 Click on the Networking tab. This tab shows network utilization.

    8 Click on the Users tab. This tab displays a list of active user sessions. The Users tab can be used to end a user's session by highlighting the user and clicking the Logoff button. Clicking the Disconnect button will end a user's session but keep it in memory so they can log on and resume the session later.

    9 Click the Processes tab and select taskmgr.exe. Click the End Process button to close the Task Manager. When prompted, choose End process to continue.

    Task 4 - Resource Monitor

    Task 4.1 - Accessing Resource Monitor in Windows 8.1

    1 While on the Win8.1 machine, right-click in the Taskbar located at the bottom and select Task Manager.

    2 Click the More Details down arrow to see the expanded mode.

    3 Click on the Performance tab in Task Manager, then click Open Resource Monitor located at the bottom of the window.

    4 The Resource Monitor opens to the Overview tab, which has links to summary graphs of activity for all tab categories and defaults to display CPU in full. Click on all the tabs in the Resource Monitor to explore the content.

    5 Click on the CPU tab. This tab shows a list of processes, the name, process ID, and status, etc. If an application is not responding, you can use the Resource Monitor CPU tab to help track down the process that is not responding. A process that is not responding will appear red in the table. Locate the explorer.exe process under the Image column, then right-click on the explorer.exe process and click on Analyze Wait Chain. If a process is stalled or hanging having to wait on another process to complete, this could cause it to freeze. Analyze Wait Chain can identify the actual process that is causing the freeze up. The unresponsive process can be closed in Resource Monitor to correct the problem.

    On the A+ exams

    Core 2: Operating Systems

    Core 2 (220-1202) lists these as tools you should recognize by name and by command: mmc, compmgmt.msc, diskmgmt.msc, taskschd.msc, eventvwr.msc, services.msc, perfmon.msc, Task Manager, resmon, and regedit. Expect scenario questions that ask which tool solves a problem.

    High-yield facts

    • A snap-in is one tool loaded into MMC; a saved console is an .msc file.
    • Task Manager's Startup tab is the first place to fix slow sign-ins.
    • Resource Monitor's Analyze Wait Chain finds what a hung process is waiting on.
    • FAT32 can't store a file larger than 4 GB; use NTFS or exFAT.
    • Initialize a new disk as GPT for drives over 2 TB and for UEFI boot.
    • Export a Registry key before editing it; a .reg file re-imports with a double-click.

    Check yourself

    1. You want one window with only Event Viewer, Services, and Disk Management for a junior tech. How?

    Open mmc, add those three snap-ins, and save it as an .msc console file.

    2. A user's PC is slow right after sign-in. Where's the quickest fix?

    Task Manager > Startup (Startup apps on Windows 11). Disable high-impact programs that don't need to start automatically.

    3. Why couldn't you copy a 6 GB video to the L: drive you created?

    L: is FAT32, which has a 4 GB maximum file size.

    4. An app is "Not responding" and ending it doesn't help for long. Which tool helps find the cause?

    Resource Monitor > CPU > right-click the process > Analyze Wait Chain, to see which process it's waiting on.

    5. You changed a Registry value and something broke. You exported the key first. How do you undo it?

    Double-click the exported .reg file (or use File > Import in Regedit) to merge the original values back.
